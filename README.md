
# QR Code Generator

A simple and user-friendly **QR code generator** application built using **Python**, **HTML**, and **CSS**.  
Easily generate and preview QR codes directly from your web browser.

---

## 🚀 Features

• 🔄 **Generate QR Codes** – Convert text or URLs into QR codes instantly  
• 👀 **Instant Preview** – View the generated QR code directly on the webpage  
• 🌐 **Web Interface** – Minimal, clean front-end for easy use

---

## 🧰 Libraries Used

• ⚙️ **Flask** – Lightweight Python web framework used to create the web server and handle user requests  
• 📦 **qrcode** – Python library used to generate QR codes from input data
